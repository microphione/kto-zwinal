# Kto zwinął?

Original grid-deduction puzzle game for the browser (mobile-first). Someone robbed the safe — place
every hero on the map using their statements and the rules, and the thief reveals themselves.

- Play: https://microphione.github.io/kto-zwinal/

- Tests: `npm test` (Node 22)
